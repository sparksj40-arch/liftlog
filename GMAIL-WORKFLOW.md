# Subscription discovery — V2.1

The approved design uses the app's direct Gmail API read-only access, not a ChatGPT scheduled task or a home server. User explicitly enables it and selects the intended Google account. Gmail API must be enabled on the OAuth project. Grants are memory-only, account-checked, separate from Sheets/Drive and Calendar; reconnect after expiration or reload. No credential, refresh token or email body is persisted. No Gmail mutation, automatic cancellation, or automatic subscription approval.

The app scans after 24 hours when open, online and authorized; manual scan bypasses interval. Recent search uses a seven-day overlap (extends back to previous successful boundary after longer gaps). Initial history is resumable in bounded pages. Review queue capped at 300; manual continuation after reviewing. Search is keyword/rule based, not exhaustive; unknown dates/currencies stay unknown. Pending candidates and checkpoints stay on the current device and are excluded from JSON backups. Approved records and explicit decisions are journaled and sync through Sheets. Review original source and select existing subscription when appropriate. Existing status, intent and protective dates are retained unless explicitly edited. No automatic cancellation inference.
